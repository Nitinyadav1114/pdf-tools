Frequently Asked Questions

Quick answers about privacy, offline capability, and browser performance

Are my PDF files really safe and never uploaded to any server? expand_more
Yes, absolutely 100%. PDF Tools operates entirely inside your web browser using pure client-side WebAssembly and JavaScript (PDF-Lib and PDF.js). When you select or drag a file into the app, your browser loads it directly from your device storage into memory. No network packets containing your document are ever transmitted over the internet.
Can I use PDF Tools when I am completely offline? expand_more
Yes! Our Service Worker precaches all required application code, libraries, and design assets on your first visit. You can install PDF Tools as a Progressive Web App (PWA) on your desktop or mobile device and run all 8 tools on airplanes, field sites, or air-gapped secure networks with zero internet access.
Is there any file size limit or daily quota? expand_more
There are zero artificial limits, no subscriptions, and no daily task quotas. Processing speed and capacity depend solely on your computer or mobile device's available RAM and CPU power. Most modern devices can easily process documents containing hundreds of pages or images.
Which browsers and operating systems are supported? expand_more
PDF Tools works on all modern web browsers supporting ES modules and HTML5 Canvas, including Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari, Brave, and Opera across Windows, macOS, Linux, Android, and iOS.
How does the Universal Dropzone work? expand_more
Our smart file router automatically inspects dropped files: if you drop multiple PDFs, it instantly routes them to the Merge tool. If you drop image files (JPG, PNG, WebP), it routes them to Image to PDF. If you drop a single PDF, a quick launcher modal opens allowing you to choose any of our 7 PDF tools with a single click.
